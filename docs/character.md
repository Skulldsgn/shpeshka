# Герой

Рабочее имя **Сёма**. Он появляется почти в каждой сцене: целиком, со спины или только руками с часами. Он и есть та самая «спешка» в человеческом виде.

## Что берём у Хьюлетта, а что нет

**Берём манеру:** контролируемая, но живая чернильная линия (часть штрихов нарочно небрежная для ощущения скорости), сильный контраст плотного чёрного и светлого, грязные фактуры и зерно, резкие диагонали и преувеличенная перспектива, панковская небрежность.

**Не берём:** внешность его персонажей, их фирменные детали (например, полностью чёрные глаза без зрачков), логотипы, имена. Герой должен узнаваться как *наш*, а не как «похож на того-то».

## Дизайн

| Черта | Зачем |
|---|---|
| Высокий, худой, сутулый, очень длинные руки и ноги | хьюлеттовские пропорции, хорошо читается в силуэте |
| Огромные кисти и стоптанные кеды | крупные планы рук (будильник, кофе, клавиатура) сразу «его» |
| Узкое длинное лицо, торчащие чёрные волосы | узнаётся даже маленьким в толпе |
| Тёмные круги под глазами, зрачки-точки, щетина | вечный недосып, тема клипа |
| **Пластырь на переносице** | фирменная деталь №1 |
| Мешковатая выцветшая оливковая парка с ржаво-оранжевой подкладкой капюшона | фирменный цвет, работает в палитре |
| Мятая белая рубашка, ослабленный ржавый галстук, серые штаны | «офисный», но потрёпанный |
| **Огромные часы на левой руке** | фирменная деталь №2, символ времени; помогает в сценах, где видны только руки |
| Бейдж на шнурке | ещё один маркер «работника» |

## Как генерировать

```bash
# 1. Лист с тремя видами — чтобы выбрать внешность (горизонтальный кадр)
python scripts/comfy.py character sheet --variants 6

# 2. Одна фигура в полный рост 9:16 — это будет «паспорт» героя для Kontext
python scripts/comfy.py character single --variants 8
```

Отберите лучший `single` и сохраните как `refs/hero.png`. Критерии:
- видны все фирменные детали (пластырь, часы, парка с оранжевым капюшоном);
- фигура целиком, от макушки до кедов, на ровном фоне;
- лицо читается, но без лишней детализации;
- нет лишних пальцев и сломанных рук: этот кадр будет копироваться во все сцены.

Если ни один не идеален, доведите лучший через Kontext точечными правками («add a small band-aid across the bridge of his nose», «make the parka hood lining rust orange»).

```bash
# 3. Позы — проверка, что Kontext держит внешность, и запас материала
python scripts/comfy.py poses refs/hero.png

# 4. Герой во всех сценах раскадровки (по 3 варианта)
python scripts/comfy.py place refs/hero.png
```

## Если внешность «плывёт» между сценами

1. Всегда давайте Kontext исходный `refs/hero.png`, а не результат прошлой правки: ошибки копятся.
2. Перечисляйте фирменные детали прямо в команде (это уже делает хвост `keep` из `prompts/character.json`).
3. Для параллакс-сцен проще вставить героя слоем: `poses` → вырезать фон → положить поверх фона сцены.
4. Когда наберётся 15–20 удачных кадров героя, обучите на них LoRA (см. `docs/pipeline.md`): это самый надёжный способ.
