# Пайплайн

Железо: RTX 5070 (12 ГБ), 32 ГБ RAM. Модели: Flux Schnell (быстрые черновики и «кипящая линия»), Flux Kontext (правки, свет, слои, выравнивание стиля).

## Общий порядок работы

```
0. герой      → refs/hero.png (docs/character.md), потом place для сцен с героем
1. keyframes  → 4–8 вариантов на сцену (Schnell, ~секунды на кадр)
2. отбор      → лучший кадр сцены в  selects/sNN.png
3. эталон     → самый удачный кадр всего клипа в  refs/style_master.png
4. выравнивание → кадры, которые выбиваются: kontext --preset restyle
5. движение   → по технике сцены: boil / daycycle / parallax / wan
6. unify.py   → все кадры всех сцен через один и тот же фильтр
7. монтаж     → DaVinci Resolve, под бит, общий LUT + зерно сверху
```

Шаг 6 обязателен для всех кадров с одинаковыми настройками: он и есть «клей», который делает стиль единым.

## Приём 1 — кипящая линия

```
python scripts/comfy.py boil selects/s01.png --scene s01 --count 4 --denoise 0.3
```
- Варианты слишком разные (плывут формы) → `--denoise 0.2`.
- Почти не отличаются → `--denoise 0.4`.
- Если Schnell всё равно меняет слишком много, используйте Kontext: `kontext selects/s01.png --preset boil --variants 4`.

В монтаже: 4 кадра по 2–3 кадра таймлайна каждый при 24 fps, зациклить.

## Приём 2 — таймлапс сменой света

```
python scripts/comfy.py kontext selects/s02.png --preset daycycle --variants 2
```
Получите 4 времени суток × 2 варианта. Выберите лучшие и при желании дополните промежуточными состояниями своей командой (`--instruction "...late afternoon..."`). Склейка по 2–4 кадра, короткие кроссфейды на 1–2 кадра.

## Приём 3 — параллакс

```
python scripts/comfy.py kontext selects/s03.png --preset clean-plate   # фон без людей
python scripts/comfy.py kontext selects/s03.png --preset cutout        # фигуры на белом
```
Белый фон вырезается в ComfyUI нодой из пакета ComfyUI-RMBG (BiRefNet) или прямо в DaVinci через Magic Mask. Слои раскладываются по дорожкам: фон двигается на 2–5%, передний план на 10–20% за сцену.

Слой с толпой лучше сделать отдельным кадром-«полосами» и зациклить горизонтальный сдвиг.

## Wan (точечно, 2–3 сцены)

Только для сцен с `technique: wan` в `prompts/scenes.json`. Брать первые 1,5–2 секунды, генерировать 3–4 варианта. Wan-клип прогоняется через `unify.py` покадрово, как и всё остальное:
```
ffmpeg -i wan_s09.mp4 frames/s09/%04d.png
python scripts/unify.py frames/s09 frames/s09_unified
```

## Единый стиль: что делать, если сцена всё равно «чужая»

По порядку, от лёгкого к тяжёлому:
1. `unify.py --strength 0.85` для этой сцены (сильнее тянет к палитре).
2. `kontext --preset restyle`.
3. Kontext с эталоном: нода Image Stitch (эталон + кадр), инструкция в `docs/style-bible.md`.
4. Перегенерировать ключевой кадр: проблема обычно в промпте сцены (слишком «фото»-слова).

## Своя LoRA (когда наберётся 15–20 удачных кадров)

Самый надёжный способ закрепить стиль. Тренируется на Flux Dev через FluxGym или ai-toolkit; 12 ГБ хватает в режиме low-VRAM. Подписи к картинкам: короткое описание содержимого + триггер-слово, например `shpshk style`. После этого её имя вписывается в `config.json → lora.name`.

## Монтаж (DaVinci Resolve)

- Проект 1080×1920, 24 fps. Ключевые кадры 768×1344 апскейлить ×1.5 (Super Scale в Resolve или 4x-UltraSharp в ComfyUI).
- Маркеры на каждый удар бочки: клавиша `M` во время проигрывания.
- На всём таймлайне Adjustment Clip: LUT `post/shpeshka_palette.cube` + Film Grain. Если кадры уже прогнаны через `unify.py`, LUT ставить слабо (Key Output Gain 0.3–0.5), чтобы не удвоить эффект.
- Safe zone: важное не ниже 75% и не выше 12% высоты кадра.
